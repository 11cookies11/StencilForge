# Session Summary - 2026-05-03

## 核心问题

本次会话围绕钢网 STL 生成质量展开，重点解决了阻焊层解析、焊盘开口完整性、开口规则、阻焊开口缩放，以及 FSM 打印机模型精度配置。

## 主要修复

### 阻焊层作为开口数据源

钢网开口现在优先使用阻焊层（GTS/GBS）。阻焊层天然描述 PCB 表面可焊接区域，比锡膏层更适合作为完整焊盘开口来源。没有阻焊层时才回退到锡膏层。

### AMGroup 与 Outline 原语解析

EasyEDA/JLC 导出的 Gerber 中大量焊盘使用 AMGroup 和 Outline 原语描述。之前这些类型没有完整解析，导致部分焊盘缺失或被拆成碎点。现在已支持：

- AMGroup：递归解析内部子原语
- Outline：将闭合线段转换成完整多边形
- 圆角矩形：按真实轮廓生成，不再退化成菱形或碎片

### 飞控板阻焊层验证

针对四轴无人机飞控板，生成了完整 2D 阻焊层图片用于人工核对，并修复了手臂区域 SOT 附近焊盘解析不完整的问题。

### 阻焊开口系数

新增 `mask_opening_scale`，默认 `0.95`。由于阻焊开口通常比铜焊盘或锡膏开口略大，进入开口规则前先对阻焊层开口做比例缩放，让钢网开口更贴近实际印刷需求。

### 开口规则默认策略

优化焊锡体积和开口调整规则：

- 新增 BGA 焊盘类型
- 默认规则从保守缩小调整为更中性的策略
- QFN、IC、BGA 等封装规则更加温和
- 规则匹配支持 Any 分组，不再误匹配封装专用规则

### FSM 打印机配置

新增 `printer_profile`：

- `generic`：通用 / 非 FSM 打印机，保持当前速度和模型复杂度
- `fsm`：FSM 3D 打印机，提高 STL 和曲线解析精度

FSM 默认参数：

- `stl_quality = high_quality`
- `stl_linear_deflection = 0.02`
- `stl_angular_deflection = 0.05`
- `arc_steps = 96`
- `curve_resolution = 24`
