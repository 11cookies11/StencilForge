# StencilForge v0.5.0 知乎文章素材整理

## 写作主题

StencilForge v0.5.0 是一次从“Gerber 转 STL 工具”向“面向真实 3D 打印钢网制造的工艺系统”的升级。

这版重点不是单纯增加参数，而是围绕实际 PCB 钢网制作中遇到的问题展开：

- paste 层信息不完整或不适合直接作为开口来源
- 阻焊层更能反映 PCB 表面可焊接区域
- 阻焊层开口通常比铜焊盘或 paste 开口略大，需要缩放
- QFN 小间距封装很难被 FDM 3D 打印机稳定打印
- 焊锡量不仅和开口面积有关，也和钢网厚度有关
- 3D 打印钢网需要和传统激光钢网不同的工艺策略

## 一句话介绍

StencilForge v0.5.0 不再只是把 Gerber 文件转换成 STL，而是开始围绕真实 PCB 钢网制造场景，加入阻焊层开口、焊锡体积计算、QFN 小间距封装优化、FDM 3D 打印模式和完整国际化支持。

## 版本定位

v0.5.0 是 StencilForge 的一次偏“工艺能力”的大版本更新。

之前的版本更像是一个 Gerber 到 STL 的转换工具，而 v0.5.0 开始处理更接近实际生产的问题：哪些层更适合作为开口来源、开口大小如何调整、焊锡量如何控制、小间距封装怎样适配 3D 打印机的能力边界。

这让 StencilForge 更接近一个“3D 打印 PCB 钢网生成器”，而不是单纯的格式转换器。

## 核心更新 1：阻焊层驱动钢网开口

过去钢网开口主要依赖 paste 层。但在实际 Gerber 中，paste 层并不总是可靠：

- 有些封装的 paste 数据可能缺失
- 有些小封装的 paste 开口可能和铜层不完全一致
- 不同 EDA 或导出设置会影响 paste 层完整性

v0.5.0 开始优先使用阻焊层 `GTS/GBS` 作为开口来源。

阻焊层本质上描述的是 PCB 表面哪些区域需要露出铜，哪些区域会被阻焊油墨覆盖。因此，它天然更接近“板子上真正可以焊接的位置”。

这对于用 3D 打印机制作钢网很重要，因为我们希望钢网开口尽量对应 PCB 表面真实焊盘，而不是完全依赖可能缺失或被特殊处理过的 paste 层。

## 核心更新 2：阻焊开口缩放系数

阻焊层虽然更完整，但阻焊开口通常会比铜焊盘或 paste 开口略大。

如果直接拿阻焊层生成钢网，可能会导致开口偏大，焊锡量过多。

所以 v0.5.0 新增了 `mask_opening_scale`，默认值为 `0.95`。

它的作用是在进入开口规则和模型生成之前，先把阻焊层开口整体缩小一点，让最终钢网开口更接近实际印刷需求。

可以理解为：

```text
阻焊层开口 -> 缩放系数修正 -> 开口规则/体积计算 -> 钢网 STL
```

## 核心更新 3：复杂 Gerber 焊盘解析修复

很多 PCB 工具导出的 Gerber 并不只包含简单的圆形、矩形、长圆形。

EasyEDA/JLC 等导出的文件中，复杂焊盘经常会以 Gerber 宏原语表示，比如：

- `AMGroup`
- `Outline`
- 圆角矩形
- 复杂组合焊盘

之前这些复杂原语没有完整解析，可能导致：

- 焊盘丢失
- 焊盘被拆成一堆小点
- 圆角矩形变成菱形或不正确的多边形

v0.5.0 修复了这些问题，让阻焊层和复杂焊盘可以更完整地还原成真实几何形状。

这部分对钢网质量非常关键，因为钢网开口的形状和位置必须尽量贴近 PCB 焊盘。

## 核心更新 4：焊锡体积与开口规则系统

v0.5.0 新增了开口规则工作台。

它不只是简单地做一个固定 offset，而是引入了更接近工艺逻辑的计算：

- 焊盘面积
- 钢网厚度
- 转印系数
- 目标焊锡体积
- 封装类型
- 焊盘类型
- 尺寸范围

通过这些参数，软件可以反推合适的开口面积。

新增能力包括：

- 按封装类型匹配规则
- 按焊盘类型匹配规则
- 按尺寸范围匹配规则
- 规则分组
- 规则导入导出
- 规则预览
- 焊锡体积计算器

这意味着 StencilForge 不再只是“把图形挖洞”，而是开始尝试控制“每个焊盘大概会得到多少焊锡”。

## 核心更新 5：更完整的焊盘类型支持

v0.5.0 增加和优化了焊盘分类能力。

目前关注的类型包括：

- SMD 贴片焊盘
- BGA 焊盘
- Thermal 热焊盘
- THT 通孔相关焊盘
- QFN / IC / Power 等封装规则分组

默认规则也从较少的模板扩展到更完整的规则集，使不同封装和不同焊盘类型可以采用不同的开口策略。

## 核心更新 6：FDM 3D 打印机模式

v0.5.0 新增 `printer_profile`：

- `generic`：通用模式
- `fdm`：FDM 3D 打印机模式

FDM 是 Fused Deposition Modeling，也就是常见的熔融沉积成型 3D 打印。

FDM 打印钢网和传统激光钢网不同，它受到喷嘴直径、层高、线宽、模型最小特征尺寸等限制。

因此 v0.5.0 增加了 FDM 模式，用于优化模型质量和工艺参数。

FDM 模式会：

- 使用更高 STL 质量
- 提高曲线分辨率
- 提高圆弧细分
- 接管钢网厚度
- 针对小间距 QFN 做特殊开口策略

## 核心更新 7：FDM 模式接管钢网厚度

在 FDM 模式下，钢网厚度不再完全依赖用户输入，而是由系统接管。

默认有效厚度为 `0.20mm`。

原因是焊锡体积和厚度直接相关：

```text
焊锡体积 ≈ 开口面积 × 钢网厚度 × 转印系数
```

如果厚度不可控，开口面积的计算就没有稳定基础。

因此 FDM 模式下使用固定有效厚度，可以让体积计算和开口调整更稳定。

## 核心更新 8：QFN 小间距封装 grouped slots

QFN 是 3D 打印钢网中很典型的难点。

很多 QFN 引脚非常窄，如果直接为每个引脚生成独立小开口，FDM 打印机可能无法稳定打印出来。

v0.5.0 针对这个问题新增 QFN grouped slots。

核心思路是：

- 不再强求每个 QFN 引脚都有独立开口
- 多个相邻引脚可以共用一个长条开口
- 通过开口面积补偿维持焊锡体积
- 尽量让长槽均匀覆盖对应引脚区域

这样可以在可打印性和焊锡量之间取得平衡。

## 核心更新 9：QFN 四角实体桥和面积补偿

QFN 外圈如果四边都开成长槽，四角可能会被切得过于脆弱，甚至形成不利于打印的断裂结构。

v0.5.0 增加了 QFN 四角实体桥。

它会在 QFN 四角保留一部分实体连接筋，让钢网结构更稳定，也更适合 FDM 打印。

但四角实体桥会吃掉一部分开口面积，所以软件又增加了宽度补偿：

- 四角保留实体桥
- 剩余槽位适当加宽
- 尽量维持原本目标焊锡体积

也就是说，目标不是单纯“形状一样”，而是尽量保证“焊锡总量接近”。

## 核心更新 10：双面钢网处理

新增 `paste_side`：

- `top`
- `bottom`
- `both`

其中 `both` 的逻辑被修正为分别生成顶层和底层两个 STL，而不是把两面合并成一个 STL。

这更符合实际生产逻辑，因为顶层和底层钢网通常是分开使用的。

## 可以重点讲的真实场景

### 场景 1：paste 层不完整

某些 PCB 中，paste 层可能没有包含所有焊盘信息。直接用 paste 层生成钢网会导致部分焊盘没有开口。

v0.5.0 改用阻焊层作为主数据源，可以更完整地找到 PCB 表面可焊接区域。

### 场景 2：阻焊层开口偏大

阻焊层为了制造公差，通常比铜焊盘略大。直接使用会导致钢网开口偏大。

v0.5.0 引入 `mask_opening_scale = 0.95`，先进行缩放修正。

### 场景 3：QFN 引脚太细，FDM 打印不出来

传统方式会给每个 QFN 引脚单独开孔，但 FDM 打印机可能无法稳定打印这些细小结构。

v0.5.0 使用 grouped slots，把多个引脚合并成长槽，并通过面积补偿控制焊锡体积。

### 场景 4：只控制形状不够，还要控制焊锡量

钢网的最终目标不是“几何上看起来像”，而是能让焊盘获得合适的焊锡量。

v0.5.0 把厚度、面积、转印系数和目标体积纳入开口计算。
